## SEMOF 그룹웨어

생활용품 프랜차이즈를 위한 그룹웨어입니다. 인사평가와 이메일 송수신 등 그룹웨어 기능을 제공합니다.

- **역할:** 인사·이메일 기능의 설계와 프론트엔드·백엔드 개발
- **인사 대시보드:** 휴가자·출근자·생일자 현황과 달력을 보여 줍니다. Elasticsearch 로 집계한 총 사원 수, 성비, 직급 비율 그래프도 넣었습니다.
- **사원 관리:** 목록, 상세, 등록, 수정, 퇴사 처리를 만들었습니다.
  - 주민등록번호 뒷자리는 화면에 보여 줄 때와 입력할 때 모두 마스킹합니다.
  - 휴대폰 번호는 입력하면 자동으로 형식이 맞춰집니다.
- **사원 이동:** 모달에서 발령 지점·부서를 고르고 저장하면 목록에 바로 반영됩니다.
- **인사 평가:** 사원의 프로젝트별 기여도 그래프와 점수 구간표를 보고 등급(A~F)을 매깁니다. 결과는 등급 카드로 쌓이고, 수정과 삭제가 됩니다.
- **이메일:** 별도 메일 서버 없이 SMTP 로 외부 메일 발송을 구현했습니다. 받은 메일함, 보낸 메일함, 휴지통, 상세 보기, 편지쓰기 모달이 있습니다.
- **공통:** 목록 화면은 10개 단위로 페이지를 나눕니다.

## BLUE Island 게시판

커뮤니티형 게시판입니다. 설계부터 배포까지 혼자 진행했습니다.

- **권한 3단계:** 비로그인은 조회만 할 수 있습니다. 사용자는 자기 글과 댓글을 수정·삭제할 수 있고, 관리자는 공지 작성과 전체 수정·삭제를 할 수 있습니다.
- **목록:** 페이지당 10개를 보여 주고, 전체 탭에서는 최신 공지 2개를 위에 고정합니다.
- **권한 오류:** 권한 없이 수정·삭제를 시도하면 안내 모달을 띄웁니다.
- **배포:** Docker 로 배포 환경을 구성했습니다.

## APOLLO 악기 판매 사이트

악기 판매·구매 플랫폼입니다. 블로그와 Q&A 게시판을 맡았습니다.

- **블로그:** 악기 구매 흥미를 높이려고 공연·악기 기사를 싣는 곳입니다. 관리자만 쓸 수 있고 사진을 첨부할 수 있습니다.
- **Q&A:** 일반 사용자 게시판입니다. 댓글 작성과 수정은 JavaScript 비동기 처리로 구현했고, 사용자와 관리자 권한을 나눴습니다.
- **FAQ:** 펼치기·접기로 동작하는 화면을 JavaScript 로 만들었습니다.

## BID & BIRD

당근마켓 같은 개인 간 거래 애플리케이션입니다. 자바 수업에서 배운 내용만으로 만든 CLI 프로그램입니다.

- 세션 기반 로그인을 구현했습니다.
- 관리자 페이지에서 회원 전체를 조회하고, 상태 값을 바꿔 탈퇴 처리를 합니다.
