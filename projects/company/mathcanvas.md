# 매쓰캔버스 — 관리자 · 사용자 화면

> 비상교육의 수학 수업 플랫폼 매쓰캔버스입니다. 콘텐츠·사용자·운영을 관리하는 **관리자
> 프론트엔드**를 주로 개발했고, 교사가 쓰는 **사용자 화면**에서도 기능을 개발했습니다.

| 항목 | 내용 |
| --- | --- |
| 기간 | 2026.04 – 2026.09 |
| 역할 | 관리자 프론트엔드 주 개발 (커밋 220여 건), 사용자 화면 기능 개발 (커밋 120여 건). 마지막에 인수인계 문서 작성 |
| 스택 | Vue 3 · TypeScript · Vite · Pinia · TanStack Query · vue-i18n · Tailwind v4 · TipTap · openapi-typescript |
| 환경 | GitLab CI → ArgoCD. 폐쇄망 개발 환경이라 새 npm 패키지를 설치할 수 없었고, 기존 의존성만으로 구현 |

## 관리자 화면

- **통합 SSO 연동.** 통합 회원 로그인을 붙이고 마이페이지는 외부로 위임했습니다. 통합회원 전환에 맞춰 사용자 목록과 상세를 바꾸고 개인정보 노출을 최소화했습니다.
- **콘텐츠 관리:** 캔버스 · 슬라이드 · 공유 콘텐츠 · 라이브러리(구 매쓰클래스) 목록과 상세 화면입니다.
  - 상태 칩, 편집기 바로가기, 추천 여부 관리를 넣었습니다.
  - 슬라이드를 라이브러리로 복제할 수 있습니다(관리자 등급 전용).
- **라이브러리 섹션 관리:** 교구별 테마 콘텐츠의 툴바 순서를 관리합니다. 교구 메타데이터를 노출합니다.
- **가이드·튜토리얼 CMS:** 트리 구조 가이드 편집(드래그 정렬)과 언어별 조회 화면입니다.
  - 리치텍스트 에디터를 **워드형으로 개편**했습니다(TipTap): 글자 크기, 줄 간격, 이미지 크기·정렬, 목록, 구분선, 유튜브 삽입.
  - 편집 유실 방지: 초안을 로컬에 보존하고, 복원하며, 이탈할 때 경고합니다.
  - 이미지 업로드 실패는 원인별(포맷 · 용량)로 안내합니다.
- **데이터 이관 화면:** 이관을 실행하고, 실행 이력을 파이프라인 형태 목록으로 보여 줍니다. 상태는 폴링하고, 실패한 작업은 다시 시작할 수 있습니다.
- **리디자인:** Figma 재추출 컬러 토큰을 3계층(원시 → 시맨틱 → 컴포넌트)으로 재편했습니다. 사이드바와 목록 테이블을 다시 디자인하고 대시보드를 새로 만들었습니다.
- **API 마이그레이션:** 새 백엔드 스펙에 맞춰 엔드포인트와 응답 형태를 옮겼습니다.
  - 도메인 명칭을 정리했습니다: mathclass→library, shared→public, deployment→activity.
  - 타입은 openapi-typescript 로 생성한 스키마에서 파생하도록 바꿨습니다.
- **에셋 관리:** 개별·일괄 활성화 처리. 토스트를 키 기반으로 정비했습니다.

## 사용자 화면

- **활동 만들기:** 기간 설정, 반응형 폼 배치, 태그를 구현했습니다. 배포된 활동을 삭제할 때 사용 중인 사용자에게 안내합니다.
- **나의 프로젝트 · 공유 프로젝트:** 필터, 검색, 빈 상태 처리, 스크랩
- **로그인 흐름:** 소셜 로그인, 비밀번호 재설정(가입된 이메일 확인), 회원가입 메일 재발송
- **가이드 뷰어:** 관리자 에디터의 서식(이미지 정렬 · 글자 크기 · 줄 간격)을 똑같이 렌더링합니다.

## 인수인계

프로젝트를 마칠 때 관리자 저장소의 인수인계 가이드를 HTML 로 작성했습니다. 구성은 부팅 순서,
인증, 라우팅 자동 수집 규약, API 타입 생성, 환경 변수, 작업별 체크리스트입니다.
