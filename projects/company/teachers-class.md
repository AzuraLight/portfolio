# 티처스 클래스 — 교재 에디터 · 관리자 · 수업 서비스

> 교사가 KIT(교구 + 차시 교재)를 골라 수업을 진행하는 서비스입니다. 관리자가 교재를 만드는
> **에디터**, 콘텐츠와 운영을 관리하는 **관리자 앱**, 교사가 수업을 여는 **강사용 앱과 수업 Player**
> 를 하나의 모노레포로 개발했습니다.

| 항목 | 내용 |
| --- | --- |
| 기간 | 2026.09 – 2026.10 |
| 역할 | 프론트엔드 단독 개발. 저장소 설계, 구현, CI/CD 를 맡음 (커밋 520여 건) |
| 스택 | Vue 3.5 · TypeScript · Vite · pnpm + Turborepo · Pinia · TanStack Query · vue-i18n(영/한) · Tailwind v4 · CodeMirror 6 · Vitest · Playwright · Storybook |
| 배포 | Dockerfile 하나로 앱별 이미지 생성 → Kubernetes. 런타임은 의존성 없는 Node 서버(정적 서빙 · SPA 폴백 · API 리버스 프록시) |

## 아키텍처

```text
apps/admin               관리자 앱 + 교재 에디터
apps/service             강사용 앱 + 수업 Player
packages/shared          공통 UI · 레이아웃 선언 · 칸(slot) · 테마 (단일 원본)
packages/lesson-renderer 교재 렌더러 — 에디터 미리보기와 Player 가 함께 사용
packages/api             OpenAPI 명세 원본 · 생성 타입 · 클라이언트
```

- 두 앱 모두 **Feature-Sliced Design** 구조입니다. 설계 결정 17건을 ADR 로 남겼습니다(FSD, 서버 상태, API 계약 패키지, 렌더러 분리 등).
- **렌더러를 독립 패키지로 분리**했습니다. 그래서 에디터 미리보기와 실제 수업 화면이 같은 코드로 그려집니다.
- **API 계약 패키지:** 관리자와 서비스 명세를 받아 타입을 생성하고, `api:check` 로 명세와 타입이 어긋났는지 CI 에서 검사합니다.
- **i18n:** 레이아웃 선언에는 글 대신 메시지 키만 둡니다. 그래서 새 언어를 추가할 때 선언을 고치지 않아도 됩니다.

## 교재 에디터

모듈(슬라이드) 단위로 차시 교재를 만드는 저작 도구입니다.

- **선언형 레이아웃 체계.** 13개 묶음(표지 · 핵심 메시지 · 그림 · 단계 · 퀴즈 · 질문 · 활동 등)의 레이아웃을 선언으로 정의합니다. 칸별 글자 수 한도와 도움말도 선언에서 자동으로 만듭니다.
- **세 가지 편집 방식.** 폼, 문서 보기, JSON 보기(CodeMirror 6)를 제공합니다. JSON 보기에는 스키마 기반 자동완성, 그 자리 밑줄 오류, 빠른 고침, 칸 설명 툴팁, 바뀐 줄 표시가 있습니다.
- **교안 가져오기·내려받기.** 교안을 JSONL · 마크다운으로 가져오고, 교재는 JSONL 로 내려받습니다. 가져오기와 내보내기를 거쳐도 내용이 그대로인지 확인하는 왕복 테스트가 있습니다.
- **협업 안전장치**
  - 차시 편집 잠금
  - 저장 충돌 창: 다른 곳에서 먼저 저장해도 내가 고친 내용을 잃지 않습니다
  - 판 기록: 이 탭에서 저장한 판으로 되돌릴 수 있습니다
  - 새로고침하면 열던 수업 · 모듈 · 페이지로 돌아옵니다
- **미리보기와 가이드.** 미리보기 새 탭은 BroadcastChannel 로 편집 내용이 바로 반영됩니다. 레이아웃 가이드 페이지에는 레이아웃별 표본과 칸 한도가 정리돼 있습니다.
- **VS Code 같은 사용성.** 명령 찾기 ⌘K, 단축키 목록 ⌘/, 교재 전체 찾아 바꾸기, 상태 막대 알림, 키보드로 칸 폭 조절, 라이트·다크 테마를 지원합니다.
- **Figma 기준 구현.** 퀴즈와 활동 레이아웃을 Figma 실측값에 맞췄고, QA 회차별 지적 사항을 반영했습니다.

## 수업 Player (강사용 앱)

- **Active Player 엔진.** 수업 엔진 위에서 도구를 애드온으로 꽂는 구조입니다. 도구는 필기, 보기, 활동 타이머, 퀴즈·활동 체크, 참고자료, 스티커 메모장입니다.
- **발표자 화면과 학생 창.** 발표자 보기는 미디어 플레이어 배치이고, 학생 창은 지목 흐름입니다. 학생 창의 영상은 발표자 창 재생을 따라갑니다.
- **수업 흐름.** 반 선택 → 차시 선택 → 수업 진행(새 탭) → 마무리 요약 → 리포트 순서입니다.
- **서비스 화면.** 랜딩, 둘러보기, KIT · 클래스 상세, 가입·로그인, My Teachers(그룹 · 리포트 · 계정)를 Figma 서비스 디자인대로 구현했습니다.
