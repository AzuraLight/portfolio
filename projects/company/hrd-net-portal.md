# HRD-Net 훈련추천시스템 포털

> 한국산업인력공단 HRD-Net 의 AI 훈련 추천 시스템 프론트엔드입니다. 기관·관리자가 쓰는
> **백오피스**와 학습자가 쓰는 **사전역량진단 → 맞춤 훈련 추천** 화면을 하나의 SPA 로 만들었습니다.

| 항목 | 내용 |
| --- | --- |
| 기간 | 2026.06 – 2026.10 |
| 역할 | 프론트엔드 단독 개발 (커밋 420여 건) |
| 스택 | Vue 3.5 · TypeScript · Vite 6 · Pinia · vue-router · vue-i18n · Tailwind v4 · Chart.js · D3 · xlsx |
| 배포 | 개발·검증용은 Docker → Kubernetes 자동 배포. 공단 운영본은 온프렘(JWS/httpd) 배포 패키지와 설치 가이드로 전달 |

## 주요 구현

### 학습자 진단 → 추천 (survey 모듈)

- 사전역량진단 설문, 진단 결과(레이더 차트), 추천 결과 목록, 추천 지식맵(force 그래프)을 만들었습니다.
- 학습 이력이 있으면 바로 결과로 가고, 없으면 역량검사로 유도하는 분기 흐름입니다.
- 즐겨찾기, 추천 만족도 피드백(의견 · 비속어 필터), 추천 이유 표시를 구현했습니다.
- 기관 사이트에 넣는 **iframe 임베드 모드**를 지원합니다. 학습자 토큰은 기관 서버가 발급해서 postMessage 로 전달합니다.
- **독립 모듈 설계.** survey 는 폴더째 다른 시스템에 이식할 수 있게 만들었습니다.
  - 호스트 기능(api · toast · 라우팅 · 추적)은 `SurveyHost` 인터페이스로만 주입받습니다.
  - 양방향 import 금지 규칙은 경계 테스트로 검사합니다.

### 백오피스

- **대시보드:** KPI, 일별·월별 추이, 기관별 활동 학습자(도넛), 시간대별 접속 히트맵, 인기 키워드 순위
- **관리 화면:** 기관 · 관리자 · 학습자 · 훈련 콘텐츠 · 커넥터(원천 데이터) · 추천 요청 이력
- **학습자 상세:** 「성장 분석 (AI)」 탭(레벨 프로파일 · 로즈 차트), AI 추천 학습 로드맵, 관심 콘텐츠
- **훈련 콘텐츠:** AI 메타데이터 편집(NCS 소분류 · 대상 직급), 개별 등록과 엑셀 일괄 등록, 연도 승계
- **이벤트:** 만족도 이벤트 응모 · 참가자 관리 · 엑셀 다운로드
- **서버 관리 화면:** 게이트웨이 파일 로그를 브라우저에서 보는 도구입니다.
  - 요청 단위로 묶은 목록과 엔드포인트 집계(2xx/4xx/5xx, 평균·최대 응답시간)를 보여 줍니다.
  - 집계 행을 누르면 해당 요청 목록으로 들어갑니다.
  - 조회 결과는 파일 mtime 기준으로 캐시하고, 화면 자신의 호출은 기본으로 숨깁니다.

## 기술적 포인트

- **API 단일 클라이언트.** 모든 호출은 `http.ts` 하나를 거칩니다. 인증 헤더를 붙이고, 오류를 정규화하고, 응답 봉투를 벗겨서 화면에 넘깁니다.
- **폐쇄망 대응.** 운영 내부망이 PATCH 와 DELETE 를 막아서 해당 호출을 POST 로 바꿨습니다. 같은 코드에서 브랜치별 배포본(개발 · v2 · 온프렘)을 cherry-pick 전략으로 관리했습니다.
- **구조 분할.** 두 번째 백엔드 연동에 대비해 `src` 를 `shared · acms · survey` 로 나눴습니다. 의존 방향은 테스트로 검사합니다. 테스트는 76개에서 245개로 늘렸고, ESLint 를 도입했습니다.
- **재사용 라이브러리화.** 지식맵과 차트는 개인 오픈소스 [vue-force-network-map](https://github.com/AzuraLight/vue-force-network-map) · [vue-bullseye-chart](https://github.com/AzuraLight/vue-bullseye-chart) 로 일반화했습니다.
